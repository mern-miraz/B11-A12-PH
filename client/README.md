# B11 A12 - Course Website

This is a frontend project built with React. It is part of my Programming Hero course assignment.

The project focuses on building a course website interface where users can explore available courses. I used modern frontend tools and libraries to build and organize the application.

## Technologies Used

- React 19
- Vite
- JavaScript
- Tailwind CSS 4
- DaisyUI
- React Router
- Firebase
- Axios
- Swiper
- Lucide React
- React Hot Toast

## Features

- React-based frontend application
- Course listing interface
- Component-based development
- Client-side routing
- Responsive styling with Tailwind CSS
- Modern UI components with DaisyUI

## Installation and Setup

Follow these steps to run the project locally.

1. Clone the repository:

```bash
git clone https://github.com/mern-miraz/B11-A12-PH.git
```

2. Go to the client directory:

```bash
cd B11-A12-PH/client
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in your terminal.

## Available Scripts

| Command | Description |

| `npm run dev` | Start the development server |
